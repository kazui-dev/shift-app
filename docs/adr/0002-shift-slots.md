# 0002 勤務時間を時間枠に集約する

- 状態：採用
- 決定記録日：2026-09-11
- 実装状況：実装済み。要件は[管理・シフト業務の設計](../design/management.md)を参照。

## 背景

勤務時間は参加できる人を見て決める。同じ勤務時間の人は枠を共有できるが、時間枠と個人の割当がそれぞれ勤務時間を持つと、両者が一致しなくなる。

## 決定

- シフトの中に時間枠を持ち、勤務時間は枠が所有する。
- メンバーの割当は必ず枠に所属する。個人だけ別の勤務時間を上書きしない。
- 勤務時間は人を割り当てる操作の中で決め、必要ならその場で枠を作る。
- 勤務時間が異なる場合は別枠へ移す。移動先もその場で作れる。
- 枠同士の時間の重なりを許可するが、同じ人の割当重複は保存しない。
- 空の枠を保持し、明示的に削除できる。
- 必要人数の時間帯は `shift_requirements` に保存し、勤務枠と割当から独立させる。必要人数を設定しても勤務枠は作らない。

## 検討した選択肢

- 枠なしの個人割当：枠単位で配置を把握・調整したいという運用に合わないため採用しない。
- 枠と個人の両方で勤務時間を保持する案：例外が増え、枠から勤務時間を判断できなくなるため採用しない。
- 枠を先に作る案：人の参加可能時間を見て勤務時間を決める流れを妨げるため採用しない。
- 必要人数を枠の定員で表す案：必要人数の時間帯と人ごとの勤務時間が一致するとは限らないため採用しない。

## 影響

- 枠の時間変更は所属メンバー全員に影響し、他の割当との重複・希望との不一致の再検証が必要になる。
- 個人の時間変更は枠間の移動として扱う。移動前後の割当履歴、欠勤連絡の参照を設計する必要がある。
- 配置画面は人の希望と割当を見ながら枠を調整できる必要がある。
- チャットは枠ごとに増やさず、シフト単位とする。
- 具体的なテーブル、既存割当の移行、識別子、競合の保存方式はこのADRでは決めない。
