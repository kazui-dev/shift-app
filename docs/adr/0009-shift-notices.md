# 0009 重要連絡と通常の会話を分離する

状態: 採用

## 決定

シフトごとの重要連絡を表示期間・本文の独立した配列として保存し、現在時刻が開始以上・終了未満の連絡だけをカレンダーと勤怠画面に表示する。本人の勤務時間との重なりでは判定しない。画面を開いたままでも開始・終了で切り替え、アプリへ戻ったときも再判定する。通常の会話は既存のシフトチャットを開いて読む。既読チェックは設けない。

2026-10-28: 当初の勤務時間との重なりによる判定は「表示期間」の解釈誤りだったため、現在時刻による判定へ訂正した。

## 理由と影響

通常チャットの全文転載は画面を長くし、重要な連絡を埋もれさせる。シフトの備考だけでは時間帯ごとの変更を表せない。個人の勤務割当へ同じ文を複製せず、シフトの基本情報でまとめて編集する。連絡はシフト本体と同じ版・認可・保存トランザクションに含め、競合で他の人の連絡を消さない。旧画面から項目が省略されたときは保存済みの値を保持する。
