## 要件

### 概要
- 旭祭実行委員会メンバーが利用するシフト管理アプリ
- 複数年度使うアプリなので、年度の概念を各所に盛り込む
- 管理者からの事務連絡や遅刻連絡などのチャット機能
- 勤怠管理
- シフト提出
- PWA（キャッシュ設定・プッシュ通知）によるオフライン時の動作担保
- Optimistic Updates

### UI
- カレンダーアプリのようなUIが望ましい
- 1日で複数のタスクやブースやイベントに配属される -> 縦型のタイムラインにする
- 旭祭期間しか使わない -> 初期画面をタイムラインにする
- 参考: Appleカレンダー(タイムライン型 トップナビゲーションに1行で日付があって綺麗)
- モバイルファースト、ボトムナビゲーション

## オフライン対応
- PWA (Service Worker) のキャッシュ
- TanStack Queryのキャッシュ（シフト情報、ユーザー情報）
- オフライン時のメッセージ送信・ステータス更新を保持

## シフト・勤怠管理
シフト提出フロー

勤怠管理はタイムライン上の出勤ボタン（勤務時間内にのみ押せる）

- 一番先に希望日時だけを集める（仕事は問わない）
- 希望日時に応じて仕事を割り振る
- 希望日時: 5分刻みくらいで送らせる？
- 希望日時とはまた別でシフト入るケースもある

**シフト管理側**
- 行/列は人/時間がいいかも？
  - 人が希望してる時間に対して仕事を割り振っていくイメージ
遅刻・欠勤時の補充
-> 空きを把握して補充を促す
シフトが変更されたときに通知

## チャット
- ルーム作成時にターゲット（単数/複数のユーザー,ロール,activity）を指定。
- オプションで発言権限を設定可能。未設定なら全員が発言可能。
- この仕様ですべてのパターンを網羅できる
	- 単数のユーザーを指定 -> "DM"
	- 複数のユーザーを指定 -> "グループチャット"
	- 担当のロールを指定 -> 担当内連絡
	- activityを指定 -> 業務連絡
	- "第n回旭祭実行委員"のロールを指定, 発言権を管理者ロールのみ設定-> 全体連絡
- ルームの作成を許可するかなどをGUI側で設定できたらなおよい。規模大きめ
- ユーザーに新しくロールがついたら、ロールがつくまえのチャットも見れるように
- ユーザーからロールが外れたら、見れなくする(?)
- 非活性化をできるようにする
